Background

What is UART?

📡 Definition

UART stands for Universal Asynchronous Receiver-Transmitter. It's a hardware communication protocol used for serial communication between devices without a shared clock.

⚡ Key Properties

• Asynchronous — no shared clock line
• Full-Duplex — TX and RX simultaneously
• Point-to-Point — 2 devices only
• Configurable — baud, parity, stop bits

🔌 Applications

• USB-to-Serial bridges (CP2102, FT232)
• Microcontroller debug console
• GPS module communication
• Bluetooth/Wi-Fi module AT commands
• FPGA-to-PC communication

📊 Common Baud Rates

9600 19200 38400 57600 115200 230400 1 Mbps

Protocol

UART Frame Format

Frame: [START][D0][D1][D2][D3][D4][D5][D6][D7][STOP]

START Bit

Always LOW (0)
Signals start of frame

Data Bits

LSB first
5, 6, 7, or 8 bits

STOP Bit

Always HIGH (1)
1 or 2 stop bits

RTL Design

Receiver FSM + Oversampling

🔬 16× Oversampling Strategy

Each bit period is divided into 16 tick slots.
START verified at tick 7 (centre).
DATA sampled at tick 15 (centre of next bits).

🛡 2-FF Metastability Synchronizer

reg rx_sync1, rx_sync2; always @(posedge clk) begin rx_sync1 <= rx; // 1st FF rx_sync2 <= rx_sync1; // 2nd FF end // rx_sync2 is metastability-free

Prevents X-propagation from asynchronous RX input into synchronous logic.
Essential for reliable operation in real FPGA hardware.

Baud Rate Generator

module baud_rate_gen #( parameter CLK_FREQ = 50_000_000, // 50 MHz parameter BAUD_RATE = 9600 )( input clk, rst_n, output reg tick // Pulses HIGH 1 clk every 1/16-baud ); localparam integer DIVISOR = CLK_FREQ / (BAUD_RATE * 16); // 50MHz / (9600 × 16) = 326 always @(posedge clk) if (count == DIVISOR - 1) begin count <= 0; tick <= 1; end else begin count <= count + 1; tick <= 0; end endmodule
